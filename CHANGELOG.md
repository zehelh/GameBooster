# Changelog


## [2.0.0-pre-release] - 2025-02-09
- Added CpuViewModel for managing CPU processes, including commands for refreshing, monitoring, setting priority, and applying gaming profiles.
- Created CpuView with a user-friendly interface for displaying CPU information and processes, including filtering options.
- Introduced data binding for CPU metrics and process management actions.
- Enhanced error handling and logging throughout the CPU management features
- Some features not implemented yet


## [1.0.0-pre-release] - 2025-06-11
- Initial project structure.
- RAM monitoring and cleaning functionalities.
- Basic UI with `egui`.
- Services management tab with Windows Defender controls.
